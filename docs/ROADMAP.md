# Roadmap FamilyCRM

Статусы: ✅ готово, 🚧 в работе / частично, ⬜ запланировано.

## Этап 0 — Фундамент и безопасность ✅

- ✅ Убрать локальные SQLite-базы и артефакты Expo из git
- ✅ bcrypt вместо несохраняемого SHA-256 (+ авто-апгрейд старых хешей при входе)
- ✅ JWT-аутентификация (`/auth/register`, `/auth/login`, `/auth/me`)
- ✅ Проверки доступа: членство в семье, роли `Parent`/`Child`, владение записями
- ✅ Alembic: начальная миграция, `create_all` убран из рантайма
- ✅ Конфигурация из окружения (`.env`), готовность к PostgreSQL
- ✅ Зафиксированные зависимости, `.env.example`, README
- ✅ Тесты на pytest с изолированной БД
- ✅ Единый API-клиент на фронтенде, демо/офлайн-заглушки входа удалены

## Этап 1 — Полноценный backend ✅

- ✅ Модели покупок (`purchases`) и журнала коинов (`coin_transactions`)
- ✅ Магазин на сервере: каталог, проверка цены и баланса, запрет повторной покупки
- ✅ Комната ребёнка через API (`GET /users/{id}/room`), история покупок
- ✅ История коинов (`GET /users/{id}/coins`): награда, отзыв, покупка
- ✅ Полный CRUD: `PATCH` событий, задач и расходов, `DELETE` расходов
- ✅ Гибкие повторения: `none` / `daily` / `weekly` / `monthly` + `recurrence_day`
- ✅ Учёт часовых поясов: UTC в API и БД, локальное время в UI
- ✅ Корректная проверка пересечений с раскрытием повторов на 366 дней
- ✅ Индексы для выборок по семье/пользователю/дате, каскады для новых таблиц
- ✅ Миграция проверена на SQLite (up/down) и PostgreSQL

## Этап 2 — Мобильное приложение ✅

- ✅ «Мой Дом»: покупки и списание коинов через API
- ✅ Календарь: локальное время, повторения, фильтрация по дню
- ✅ Финансы: удаление расходов
- ✅ Сохранение JWT между перезапусками (`expo-secure-store`, веб — `localStorage`)
- ✅ Восстановление сессии при запуске (`/auth/me`) и splash-экран
- ✅ Автоопределение адреса API по Expo-хосту (телефон видит backend по Wi-Fi)
- ✅ Локатор: `expo-location` (разрешения, реальные координаты)
- ✅ Карта семьи: `react-native-maps` на iOS/Android, веб-фолбэк
- ✅ Реалтайм: WebSocket `/ws/families/{id}`, автопереподключение,
  polling раз в 30 с как страховка
- ✅ Редактирование задач и событий из UI (модальные формы)
- ✅ Обновление комнаты при изменении баланса коинов

## Этап 3 — Продуктовые функции 🚧

- ✅ Ролевой интерфейс: задачи создаёт только родитель, форма скрыта у ребёнка
- ✅ Профиль: аватар (эмодзи), имя, отдельная вкладка
- ✅ Смена пароля из профиля (`POST /auth/change-password`)
- ✅ Бюджеты по категориям на месяц + индикатор перерасхода
- ✅ Фильтры финансов: месяц и категория
- ✅ Вид месяца в календаре с отметками событий
- ✅ Дата окончания повторяющейся серии (`recurrence_until`)
- ⬜ Восстановление пароля по email (нужен почтовый провайдер)
- ⬜ Push-уведомления о событиях и задачах (нужен dev build/EAS)
- ⬜ Фоновая геолокация и геозоны (школа/дом)
- ⬜ Точечные эндпоинты вместо `/overview` в приложении
